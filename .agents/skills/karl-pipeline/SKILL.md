# KARL pipeline

When available, read [the RNO KARL reference](references/karl-pipeline.md)
for the relevant stage or procedure. It records dated experiment state, so
check the current repository and configuration before acting. Without that
local reference, inspect the KARL pipeline in the active mistral worktree and
follow its current stage configuration. Use `uv run --frozen` for commands.
